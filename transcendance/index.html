transcendance

Créer un site internet autour du célèbre jeu pong

Langage : Typescript, SQL

Technologies : NGINX, Docker, sqlite

Projet : 42

Repository : https://github.com/ma-gabriel/ft_trancendence

Le projet

Nous devions faire en groupe de 3 un site internet basé autour du jeu pong, avec système de compte, de canal de discussion, d'avatar, ainsi que les essentiels: sécurité, gestion de données, confort, etc.

Nous avions comme consignes d'utiliser un backend avec fastify (typescript) et un front end en Javascript natif (donc réalisé en typescript également) avce comme framework Tailwindcss. La base de donnée étée réalisée avec sqlite.

Ce que j'ai appris

Ce projet m'a appris le travail de groupe et les bonnes pratiques git, en plus évidemment de faire du web en natif, de gérer des données sensibles et bien d'autre
